\subsection{Doctrine}
To approach AlphaFold-class \emph{discipline} (\(\le 1\%\) on primary ephys locks)
without inventing free parameters on \(S\):
\begin{enumerate}[leftmargin=*]
  \item Keep seeds, codon map, and \(S\) law fixed.
  \item Adjust only \textbf{phenotype timing knobs} already used by scalpel:
        refractory steps \(R\), FI drive, threshold, adapt step.
  \item Step sizes scaled by seeds \(\varphi,e,\pi\) (multiplicative factors),
        not learned coefficients.
  \item Remeasure FI-window rates against Allen means after each micro-step.
\end{enumerate}

\subsection{Algorithm sketch}
Given class \(c\) with relative error \(\varepsilon=(m-t)/t\):
\begin{align}
R &\leftarrow R + \mathrm{sign}(\varepsilon)\cdot\Big\lceil \varphi\cdot\mathbf{1}_{|\varepsilon|>0.01}\Big\rceil,\\
\mathrm{FI} &\leftarrow \mathrm{FI}\cdot\bigl(1 - \mathrm{sign}(\varepsilon)\cdot\tfrac{1}{e\pi}\cdot\min(1,|\varepsilon|/0.02)\bigr),
\end{align}
then remeasure. Iterate until \(|\varepsilon|\le 0.01\) or iteration budget
exhausted. Implementation: \texttt{run\_precision\_climb.py}.
