## Bridge gap (honest)

```text
Today:   FSOT trits / S / fingerprints  ←→  machine words / chemical codons
Later:   same internal state            ←→  natural language text benchmarks
                                          (IMDB, Shakespeare, etc. as *tests*)
```

We do **not** fine-tune a free-parameter LM on IMDB.  
We **do** keep corpora so that when encode/retrieve + study-EEG + multi-region memory are strong enough, we can:

1. Encode passages as machine trit streams  
2. Retrieve / complete under FSOT dynamics  
3. Score against human-readable gold (sentiment, paraphrase, literature line ID)  
4. Treat that as an **intelligence ladder**, not an NLP competition product
